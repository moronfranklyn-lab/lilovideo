# 记忆索引

> 这个文件夹是项目的记忆层：跨会话保存"做到哪了、定了什么、怎么干活"。
> 每次新会话开始时，按下面顺序读。

## 阅读顺序

| 顺序 | 文件 | 读它的目的 | 何时读 |
| --- | --- | --- | --- |
| 1 | [项目状态.md](项目状态.md) | 现在处于哪个阶段、上次停在哪、有哪些待确认问题 | 每次会话第一件事 |
| 2 | [上下文备忘.md](上下文备忘.md) | 路径约定、常用命令、环境坑、既有约定 | 动手前必读 |
| 3 | [阶段文档/](../阶段文档/) | 本阶段的技术方案与产出清单 | 进入具体阶段时 |
| 4 | [证据包](../evidence/) | 每个阶段的验收证据 | 验收时 |

## 本文件夹的规则

- **密钥、AccessKey、邀请码一律不写入任何记忆文件。**
- 已定的决策记入《项目状态.md》的决策台账，之后不再重复询问。
- 决策台账最多 10 项。超出时把已完成的归档到《归档决策.md》。
- 待确认问题用决策卡格式：问题 / 选项 / 推荐 / 不选的后果。
- 一次最多抛出 5 个必须回答的问题。

## 记忆层的边界

| 位置 | 上传 GitHub | 内容 |
| --- | --- | --- |
| `lilovideo/docs/memory/` | 是 | 项目状态、上下文、阶段文档。可公开，不含敏感策略 |
| 工作区根的 `docs/memory/` | 否 | 个人笔记，不随仓库发布 |

**技术实现与项目进度**放仓库内的 `docs/memory/`。
**个人策略与对外话术**放工作区根目录的 `docs/memory/`。

两者不要互相引用，避免公开仓库出现指向库外文件的链接。

## 各文件职责

### 项目状态.md

回答"现在到哪了"。

- 当前阶段与上次停在哪
- 决策台账（不超过 10 项）
- 待确认问题
- 环境台账
- 阶段历史

### 上下文备忘.md

回答"怎么干活"。

- 路径约定（工作区根与仓库根的区别）
- 工具链位置（刻意装在外接磁盘）
- 常用命令
- 环境坑与绕过方法
- 既有约定（来自开发助手框架）
- 产品硬约束

### 阶段文档/

回答"这个阶段要做什么、做成什么样"。

每个阶段一份，包含目标、范围、技术方案、产出清单、验收条件。

## 维护要求

- 每个阶段结束时更新《项目状态.md》的阶段历史。
- 承诺的证据包必须交付到 `docs/evidence/阶段N/`。
- 阶段闸门是否表任一项为"否"时，不得宣布该阶段完成。
- 环境或路径约定发生变化时，同步更新《上下文备忘.md》。
