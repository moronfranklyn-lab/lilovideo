## 1. 选定方案

从四个方向中选出「**框中有光**」：

| 方向 | 16px 表现 | 结论 |
| --- | --- | --- |
| A 光圈 | 线条糊掉，叶形消失 | 淘汰 |
| **B 框中有光** | **仍能读出「画框 + 播放」** | **选定** |
| C 连成一线 | 三段消失，只剩箭头 | 淘汰 |
| D 字标 L | 笔画糊成黑块 | 淘汰 |

**选定理由**：语义最直白（分镜画幅 + 播放），且是唯一在 16px 下仍保留可辨结构的方案。

四个方向的原始文件保留在 `concept-*.svg`，便于日后回溯比较。

## 3. 两套变体的差异（刻意的光学补偿）

不是简单缩放，是针对尺寸重新调参：

| 项目 | 主变体（≥32px） | 小尺寸变体（≤24px） |
| --- | --- | --- |
| 画框描边 | 3.6 | **4.6**（细线会被抗锯齿抹淡） |
| 画框尺寸 | 39 × 35 | **43 × 37**（撑满可用空间） |
| 播放符占比 | 画幅内宽约 46% | **约 56%**（实心块比线条更耐缩放） |
| 圆角 | rx 7.5 | rx 6.5（圆角会吃掉边长） |
| 创意点 | 有 | **无**（16px 下仅约 1px，会变噪点） |
| 填充方式 | 渐变 | **纯色**（小尺寸看不出渐变，少一个失败点） |

| 用途 | 值 | 说明 |

| 底板 | `#1B1B23` | 与界面卡片同色，保证在任意背景上一致 |

| 渐变（大尺寸版） | `#FF9A6B` → `#E8642F` | 深色表面上略提亮，补偿暗底对暖色的吸收 |

## 5. 踩到的坑（重要，避免重复）

### 坑一：XML 注释内不得出现双连字符

**症状**：SVG 文件能正常返回（HTTP 200），但浏览器**完全不渲染**，`naturalWidth` 为 0。

**原因**：XML 规范规定 `--` 是注释结束标记，注释体内出现 `--` 会导致整个文件解析失败。

**触发方式出乎意料**：用 `--------` 当注释分隔线，以及**在注释里写 CSS 变量名**（如 `--lp-accent`）都会触发。

**教训**：注释里用 `====` 作分隔线；提到 CSS 变量时不要带 `--` 前缀。

**校验方法**：`docs/design/icons/` 下的校验脚本会同时检查双连字符与 XML 可解析性。

### 坑二：多张 SVG 同页时的 url(#id) 串扰

同页出现多张 SVG 且渐变 id 相同时，`url(#id)` 可能被解析到别的文档，导致引用失效。

**应对**：小尺寸变体干脆不用渐变，改用纯色。少一个装饰就少一个失败点。

## 6. 使用建议

| 场景 | 尺寸 | 用哪个 |
| --- | --- | --- |
| 浏览器标签页 / favicon | 16 / 32 | 小尺寸变体 |
| 侧栏品牌标 | 24–28 | 小尺寸变体 |
| 页面头部 / 应用图标 | 40–64 | 二者皆可，主变体略丰富 |
| 官网 / 宣传物料 | ≥96 | 主变体（可用创意点） |
