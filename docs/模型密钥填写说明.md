# 模型密钥填写说明

配置过程只需要 **5 分钟**，填 **2 个 Key**。

---

## 一、要填的文件

```
lilovideo/src/backend/config.yaml
```

用任意文本编辑器打开它。搜索 `填这里`，会找到 **2 处**要填的地方。

> 这个文件已被 `.gitignore` 排除，**不会被上传到 GitHub**。

---

## 二、第 1 个 Key：通义 DashScope

**用途**：写剧本、设计角色与场景、评估生成的图片。

### 申请步骤

1. 打开 https://bailian.console.aliyun.com/
2. 用阿里云账号登录（没有就注册一个，需要实名认证）
3. 首次使用需要**开通百炼服务**，按页面提示点"开通"
4. 开通后，点右上角头像 → 「API-KEY」→ 「创建我的 API-KEY」
5. 复制生成的 Key（形如 `sk-xxxxxxxxxxxxxxxx`）

### 填到哪里

在 `config.yaml` 里找到这一段：

```yaml
  dashscope:
    api_key: ''                # ← 填这里（第 1 处）
```

把 Key 粘到两个单引号**中间**：

```yaml
  dashscope:
    api_key: 'sk-你复制的Key'
```

---

## 三、第 2 个 Key：火山方舟 ARK

**用途**：生成角色图、场景图、分镜参考图、视频片段。

### 申请步骤

1. 打开 https://console.volcengine.com/ark
2. 用火山引擎账号登录（没有就用手机号注册）
3. 首次使用需要**开通方舟服务**
4. 左侧菜单找到「API Key 管理」→ 「创建 API Key」
5. 复制生成的 Key

### 重要：确认模型已开通

在方舟控制台左侧菜单找到「开通管理」，确认这两个模型处于**已开通**状态：

| 模型 | 用途 |
| --- | --- |
| **Doubao-Seedance-2.0** | 视频生成 |
| **Doubao-Seedream-5.0** | 图片生成 |

如果显示未开通，点开通即可（注意：开通本身通常不收费，**实际调用才计费**）。

### 填到哪里

在 `config.yaml` 里找到这一段：

```yaml
  ark:
    api_key: ''                # ← 填这里（第 2 处）
```

填好后：

```yaml
  ark:
    api_key: '你复制的火山方舟Key'
```

---

## 四、检查有没有填对

两个 Key 都填好后，保存文件，然后在项目目录运行：

```bash
cd lilovideo/src/backend
.venv/bin/python -c "
import yaml
c = yaml.safe_load(open('config.yaml', encoding='utf-8'))
p = c['api_providers']
for n in ('dashscope','ark'):
    k = (p.get(n) or {}).get('api_key','').strip()
    print(f'{n:12} {\"已填写\" if k else \"还没填\"}')
"
```

看到两行都显示 **已填写**，就说明填对了。

---

## 五、这次会用到的模型

已在 `config.yaml` 里配好，你不需要改：

| 环节 | 模型 | 平台 |
| --- | --- | --- |
| 写剧本 | `qwen-max` | 通义 |
| 评估角色图 | `qwen3.7-plus` | 通义 |
| 生成角色/场景/参考图 | `doubao-seedream-5-0-260128` | 火山方舟 |
| 生成视频片段 | `doubao-seedance-2-0-260128`（Seedance 2.0） | 火山方舟 |

**关于 Seedance 2.5**：后端当前版本只支持到 Seedance 2.0，没有 2.5。如需 2.5 要先做适配。

**关于 `qwen3.5-plus`**：不要写这个模型名。后端代码对 `qwen3.5` 开头的名字有兼容降级处理，会被自动改成 `qwen-plus`，达不到预期效果。

## 六、费用提醒

**开通服务不收费，实际调用才计费。** 按本项目的规格（1 集、6–8 个镜头、约 1 分钟），单条成片的预估花费在 **10–20 元**之间。

建议先去两个平台的费用中心确认一下余额或免费额度。如果只想先试试，可以在生成到某个阶段时停下，不跑完整个流程。
