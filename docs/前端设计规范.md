# 前端设计规范

> 方向：**好上手的消费级创作工具**。
> 目标：第一次来的用户不需要理解任何技术概念，输入一句话就能开始。
> 本文件定义设计 token 与交互原则，前端代码以此为准。

---

## 1. 设计立场

### 一句话

**界面安静，画面发光。**

产品的主体是 AI 生成的影像。界面的职责是让用户聚焦在创意与产物上，而不是让用户欣赏界面。所以：暗底、低饱和、克制的控件、让生成的画面成为页面上唯一的亮点。

### 为什么是暗色而不是浅色

参考的两份设计系统走了两个极端：[Luma](https://github.com/educlopez/design-bites/blob/main/design-mds/lumalabs.ai/DESIGN.md) 是纯白极简（营销落地页），[Pika](https://github.com/Khalidabdi1/design-ai/blob/main/design-md/pika/DESIGN.md) 是近黑加高饱和渐变（消费级产品）。

选择暗色的理由：

1. **视频与图片在暗底上观感更好**。这是视频类产品的物理事实——亮底会把画面里的暗部压死。
2. **与"消费级"定位匹配**。Pika 的暗色方案证明了这条路的可行性。
3. **但不照搬 Pika 的高饱和渐变**。品红到紫的强渐变偏"娱乐型"，也会和生成画面的颜色打架。

所以取两者的交集：**Pika 的暗色骨架 + Luma 的克制**，只保留一个低饱和强调色。

## 2. 设计 Token

### 2.1 色彩

暗色中性色阶 + 单一强调色。所有颜色用 CSS 变量定义在 `app/globals.css`。

```css
/* 底层与表面：逐级提亮，靠明度差而非阴影建立层次 */
--lv-bg:          #0B0B0F;   /* 页面底色 */
--lv-surface:     #13131A;   /* 卡片、面板 */
--lv-surface-2:   #1B1B24;   /* 浮层、下拉、弹窗 */
--lv-surface-3:   #23232E;   /* 悬浮态、选中底色 */

/* 描边：发丝级，暗色下必须比亮色更谨慎 */
--lv-border:      #26262F;
--lv-border-strong: #34343F;

/* 文字：三级足够，不要更多 */
--lv-text:        #F0F0F5;   /* 主文字 */
--lv-text-2:      #A0A0B0;   /* 次要、说明 */
--lv-text-3:      #6B6B7B;   /* 占位符、禁用 */

/* 强调色：只用一个，低饱和暖橙，友好不侵略 */
--lv-accent:      #FF7A45;
--lv-accent-hover:#FF8F61;
--lv-accent-soft: rgba(255, 122, 69, 0.12);   /* 选中底、焦点光晕 */

/* 状态色：仅用于语义，不做装饰 */
--lv-success:     #3ECF8E;
--lv-warning:     #F5B544;
--lv-danger:      #F2555A;
```

**为什么强调色选暖橙而不是品红或蓝**：

- 品红紫是 Pika 的品牌资产，抄它既是模仿也偏"娱乐"
- 蓝色是最常见的安全选择，但暗色底上的蓝容易显得冷、像运维后台
- 暖橙在暗底上足够跳，语义上接近"创作、能量"，且与大多数画面色调不冲突

**强调色的使用纪律**：全局只允许出现在**主操作按钮**、**当前选中项**、**焦点描边**三处。不要用它做装饰线、图标着色或标题高亮。

### 2.2 排版

系统字体栈，不引入 Web 字体（减少首屏负担，中文也不必等字体）。

```css
--lv-font: -apple-system, BlinkMacSystemFont, "PingFang SC",
           "Hiragino Sans GB", "Microsoft YaHei", system-ui, sans-serif;
```

| 用途 | 字号 | 字重 | 行高 | 字距 |
| --- | --- | --- | --- | --- |
| 首页主标题 | 28px | 600 | 1.3 | -0.5px |
| 区块标题 | 18px | 600 | 1.4 | -0.2px |
| 正文 / 输入 | 15px | 400 | 1.6 | 0 |
| 次要说明 | 13px | 400 | 1.5 | 0 |
| 标签 / chip | 13px | 500 | 1.4 | 0 |
| 极小标注 | 11px | 400 | 1.3 | 0 |

**层级靠字号不靠字重**：主标题 600、区块标题 600、正文 400 已是全部。不要引入 300 或 700。

### 2.3 间距与圆角

4px 基准栅格。

```css
--lv-space-1: 4px;   --lv-space-2: 8px;   --lv-space-3: 12px;
--lv-space-4: 16px;  --lv-space-5: 24px;  --lv-space-6: 32px;
--lv-space-7: 48px;  --lv-space-8: 64px;

--lv-radius-sm: 8px;    /* 小控件、chip */
--lv-radius-md: 12px;   /* 按钮、输入框 */
--lv-radius-lg: 16px;   /* 卡片 */
--lv-radius-xl: 24px;   /* 大面板、弹窗 */
--lv-radius-pill: 999px;
```

**圆角纪律**：按钮和输入框用 `md`，卡片用 `lg`，弹窗用 `xl`。**只有"主操作按钮"和"chip"允许用胶囊形**——否则满屏胶囊会失去重点。

### 2.4 深度

**默认不用阴影**（沿用 Luma 的立场）。层次靠：

1. 表面明度差（`bg` → `surface` → `surface-2`）
2. 发丝描边

**唯一允许阴影的地方**：浮层（下拉、弹窗、Toast），因为它们在内容之上，需要明确脱离页面。

```css
--lv-shadow-overlay: 0 16px 48px rgba(0, 0, 0, 0.6);
```

## 3. 交互原则（好上手的核心）

### 原则一：默认值必须能直接跑通

用户什么都不选，也必须能生成出东西。所有技术参数都有合理的默认值，且默认值经过验证。

### 原则二：技术参数默认折叠

生成参数（模型、分辨率、生成方式）默认收在「高级设置」里。首次进入的用户完全看不到它们。

> 这是本次改版**最重要的改动**。现状首页一上来就摊开 8 个选择器，把技术决策前置到了用户还没有任何产物的时刻。

### 原则三：用画面代替文字做选择

用户分不清"首帧生视频 / 首尾帧 / 参考图生视频"。**给三种方式配示意图**，用一张图说清差异，而不是三段说明文字。

### 原则四：主路径只有一条

首页只有一个显眼的操作：「开始创作」。其他能力（临时工作台、三条 Pipeline）收到侧栏，不参与首页竞争。

### 原则五：进度必须可见且说人话

7 个阶段对用户是黑盒。要显示为一条进度，且用创作者能懂的话：

| 阶段 | 对用户显示 |
| --- | --- |
| script_generation | 写剧本 |
| character_design | 定角色 |
| storyboard | 排镜头 |
| reference_generation | 画画面 |
| video_generation | 生成视频 |
| post_production | 剪辑成片 |

不要显示 `script_generation` 这类内部名。

### 原则六：每个停点都说清"现在能做什么"

停在某个阶段时，界面上必须同时给出：**当前产出了什么**、**可以改什么**、**下一步会怎样**。不要让用户猜。

## 4. 首页结构（改版后）

```
┌──────────────────────────────────────────────────────┐
│  侧栏                    │  主区                      │
│  · 我的项目              │  ┌────────────────────┐   │
│  · 临时工作台            │  │  一句话，开始创作    │   │
│  · 文艺短视频            │  │  ┌──────────────┐  │   │
│  · 动作迁移              │  │  │ 输入框        │  │   │
│  · 数字人口播            │  │  └──────────────┘  │   │
│                          │  │  [开始创作]        │   │
│                          │  └────────────────────┘   │
│                          │                            │
│                          │  ▸ 高级设置（默认折叠）     │
│                          │                            │
│                          │  试试这些（灵感卡片）       │
│                          │  [图][图][图]              │
│                          │  [图][图][图]              │
│                          │                            │
│                          │  最近的项目                │
│                          └────────────────────────────┘
```

**从上到下的信息优先级**：输入 → 开始 → 灵感 → 历史。技术参数不在主视野内。

## 5. 实施范围

### 本次改版做

| 项 | 说明 |
| --- | --- |
| 建立 token 体系 | `globals.css` 中定义全部变量，替换现有硬编码色值 |
| 首页结构重排 | 输入优先，技术参数折叠进「高级设置」 |
| 品牌与文案 | 统一为 Lilovideo，文案改为创作者语言 |
| 7 阶段中文名 | 进度显示用「写剧本 / 定角色 / 排镜头 / 画画面 / 生成视频 / 剪辑成片」 |
| 组件状态补全 | 主按钮的 hover / focus / disabled / loading 四态 |

### 本次不做

| 项 | 原因 |
| --- | --- |
| 摄像机控制、镜头参数 | 专业向，与好上手冲突，且后端不支持 |
| 无限画布 / 节点连线 | 工作量超出当前范围 |
| 成本面板 | 属阶段 3 后续子阶段 |
| 单镜头重做的交互改动 | 逻辑已有，仅需视觉对齐 |

---

## 6. 验收方式

1. 第一次打开首页，**不需要做任何选择**就能输入并提交
2. 首页首屏可见的技术选择器数量为 **0**（全部在「高级设置」内）
3. 每个主按钮具备 default / hover / focus / disabled / loading 状态
4. 7 个阶段在界面上显示为中文创作语言，不出现内部字段名
5. 在 1440 / 1024 / 768 / 375 四个宽度下无横向溢出
