## 2. 一个反直觉的成本事实（必须知道）

**各档的毛利比例完全相同（都是 1.4 倍率），但绝对利润随成本线性增长。**

| 档位 | 5 秒成本 | 5 秒实付 | **绝对毛利** | 毛利率 |
| --- | ---: | ---: | ---: | ---: |
| 特价 | ¥0.75 | ¥3.50 | ¥2.75 | 79% |
| 入门 | ¥1.50 | ¥7.35 | ¥5.85 | 79% |
| 标准 | ¥3.00 | ¥14.70 | ¥11.70 | 79% |
| 高质 | ¥4.00 | ¥19.60 | ¥15.60 | 79% |
| 高端 | ¥7.56 | ¥37.10 | **¥29.54** | 79% |

**结论一**：卖一个高端片段 ≈ 卖 **11** 个特价片段的利润。**高端档要推，不是要藏。**

**结论二（更重要）**：**特价档必须限量。**
若全部用量走特价档，平台每 5 秒只赚 ¥2.75，而一次完整成片含 3 个片段加全套前期，
利润会被压到很薄。**特价的作用是拉新，不是承接全部用量。**

## 3. 特价机制怎么设计

**「特价」不改公式，而是改用户买积分的价格。** 这样规则保持统一。

### 3.1 三种特价手段

| 手段 | 做什么 | 平台代价 | 适用 |
| --- | --- | --- | --- |
| **限时折扣** | 某档位在指定时间内积分消耗打 X 折 | 该档毛利下降 | 拉新、活动期 |
| **赠送额度** | 注册 / 活动赠积分 | 一次性成本 | 拉新 |
| **积分卡加赠** | 买卡多送 N% 积分 | 摊薄该卡毛利 | 促充值 |

### 3.2 折扣的安全下限

设某档打 X 折，则：

```
实付 = 积分 × 单价 × X
     = (成本 × 10 × K) × (K × 0.25) × X      ← K 在积分和单价里各出现一次
     = 成本 × 2.5K² × X
不亏本条件：2.5K² × X > 1   →   X > 1/(2.5K²)
```

| K | 实付倍数 | 安全折扣下限（毛利 0） |
| ---: | ---: | ---: |
| 1.4 | 4.90 | **X > 20.4%** |

> **这个 20.4% 被两次误判过，两次的原因不同，都记下来。**
>
> 第一次：一个校验脚本按 `2.5K` 复算得到 28.6%，与文档的 20.4% 不一致。
> 当时的结论是"文档对、脚本错"——**结论没错，但理由是错的**：
> 脚本用的系数确实是错的，可是文档用来支撑 20.4% 的代数式 `3.5K` 也是错的
> （它把 K 代进了一处、留了一处）。两个错误在 K=1.4 时数值接近，所以被掩盖了。
>
> 第二次：把实付倍数彻底算清楚后才发现，**正确系数是 `2.5K²`**（不是 2.5K，也不是 3.5K），
> K=1.4 时恰好也是 4.90，因此 **20.4% 从一开始就是对的**。
> 详见《积分与会员模型.md》§2.4。现在系数写在 `models/credits.py` 的
> `discount_floor()` 里，不再靠人记。
>
> **结论不变**：K=1.4 时打 2 折以上都不亏本（毛利为 0）。
> 这只是**不亏本**。要保住基本毛利需自行设目标，见下表。

### 3.3 建议的特价规则（含毛利约束）

| 规则 | 折扣 | 实际毛利 | 用途 |
| --- | --- | --- | --- |
| **新用户首条样片免费** | 100% | 负 ¥0.75 | 拉新，成本极低 |
| 特价档限时 5 折 | 50% | 59% | 活动期引流 |
| 特价档常规 | 不打折 | 79% | 日常 |
| **特价档每人每月上限** | — | — | **建议 20 个片段**，防止全部用量走特价 |

**「新用户首条样片免费」值得特别推荐**：成本只有 ¥0.75，
但用户能完整体验「创意 → 看到动态画面」，这是转化率最高的一笔投入。

### 3.4 组合计价（套餐）

套餐属于「卖积分的价格」，不是「改单价」。两种做法：

| 做法 | 说明 | 例子 |
| --- | --- | --- |
| **纯积分包**（推荐） | 买积分越多单价越低 | ¥91 / 260 积分；¥900 / 2,570 积分 |
| **场景套餐** | 按「一条成片」打包，含指定档位额度 | 「成片包」= 前期积分 + 3 个高端档片段 |

**推荐先做纯积分包**，理由：规则最简单，用户跨档位自由组合，
不必为每种模型组合设计套餐。

**场景套餐的问题**：一旦把档位写进套餐，用户换档就要换套餐，规则复杂且易纠纷。

## 4. 用户自选模型：三种粒度

产品决策要求「用户也可以自己选模型做」。三个粒度建议**全部提供**：

| 粒度 | 选择位置 | 作用 | 状态 |
| --- | --- | --- | --- |
| **项目级** | 创建项目时的「高级设置」 | 一次性定默认档位 | **已有** |
| **片段级** | 视频阶段每个片段旁 | 关键镜头用高档，过渡镜头用低档 | 待做 |
| **重做级** | 单镜头重做时 | 重做时可换档位 | 待做 |

### 为什么片段级最重要

**它才是「组合」的核心价值。** 一条片子里，观众注意力集中的镜头只有少数：

```
镜头1 建立环境   → 特价档就够
镜头2 人物特写   → 高端档（脸不能崩）
镜头3 动作过渡   → 入门档
镜头4 情绪高潮   → 高端档
```

用户按镜头重要性分配预算，**这是真省钱且不掉质量的做法**。
行业里 Runway 官方也建议「Turbo 打草稿、Gen-4.5 出成片」。

### 片段级选择必须配的三样东西

| 必须显示 | 原因 |
| --- | --- |
| 每个档位的**积分单价** | 用户要能算 |
| 该片段的**预估消耗** | 避免生成后才发现贵 |
| **推荐档位** | 见第 5 节 |

## 5. 最大的风险：用户不知道怎么选

给用户五档而不给指导，等于把决策成本丢给用户，结果是他随便挑一个然后不满意。

| 引导方式 | 做法 |
| --- | --- |
| **默认档位** | 默认「标准」档，不是最便宜也不是最贵 |
| **场景推荐** | 创建项目时按题材推荐（短剧→高端、口播→入门） |
| **质量对比样例** | 同一提示词各档输出并列 |
| **样片机制**（已实现） | 先用特价档出样片，确认后再定档生成其余 |

### 质量对比样例是必须做的

**这是目前唯一缺的关键材料。** 没有它，用户无法判断「多花 6 倍积分值不值」。

**做法**：同一段提示词、同一个首帧，跑五个档位各生成一个 5 秒片段，做成并列对比（含成本标注）。

| | |
| --- | --- |
| **成本** | 约 ¥15（五个 5 秒片段） |
| **收益** | 一份材料同时解决三件事：用户能判断档位差距、我们能验证价差是否合理、文档有可引用依据 |

## 6. 与既有规则的关系

```
底层：成本核算（已实现）
  记录每次调用的真实花费
        ↓ 按统一倍率换算
计算层：积分消耗（本文档）
  积分 = 成本 × 10 × K        ← 换模型只改数值，不改规则
        ↓ 按购买方式换算
购买层：用户实付
  积分卡 / 会员赠积分 / 特价折扣    ← 特价与套餐在这一层做
```

**关键设计**：**特价与套餐只改「买积分的价格」，不改「积分消耗的规则」。**

好处：

- 规则统一，用户只需理解一件事：好模型消耗更多积分
- 促销结束只需恢复原价，不必回改消耗表
- 新增模型只加成本与单价，不动促销逻辑
