### 模型开通的坑

- **方舟的 Seedream 5.0 和 4.5 未开通**，账号里只有 4.0 可用，已改用 4.0
- **方舟没有 LLM 和 VLM**，语言与视觉能力必须走通义，这是双平台配置的原因
- **2026-09-23 更正：「Seedance 2.5 不存在」是错的。** 当时用自己猜的模型 ID
  去调，报 `404 InvalidEndpointOrModel.NotFound`，就误判为"没有这个模型"。
  改用 `GET /api/v3/models` 列账号可见模型后确认：**2.5、2.0 mini、1.5 pro、
  1.0 pro 全都在**，先前失败只是 ID 写错（如 `doubao-seedance-2-0-mini-t2v`
  真实 ID 是 `doubao-seedance-2-0-mini-260615`）。
  **教训：判断"有没有某个模型"要查模型列表接口，不能用"调不通"来推断。**
